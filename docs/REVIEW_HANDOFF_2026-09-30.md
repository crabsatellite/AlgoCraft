  已有缓存保留。打包 JSON 统一 LF，修复 Windows 换行导致 manifest 哈希不符。
- 客户端自动测试创建窗口前隐藏，不聚焦、不全屏、不捕获/移动硬件鼠标，隔离
  系统剪贴板，静音 OpenAL 设备。限制 4 GiB / 2 个处理器 / 60 FPS，退出恢复配置。
- 自定义客户端任务明确连接共享运行锁，收据包含会话、源码与截图哈希、清理和
  实际退出结果。完整客户端验收用一个世界内的 10 轮流程，避免重复启动。
- 更新 README 的使用路径、ECJ 编译器及服务器独立判题说明。
- 将被遗留巨型测试类一起排除的 67 项缓存、下载、回滚、并发刷新、状态清理、

## 人工验收建议

1. 使用新测试目录加载产物，放置并右键算法电脑，确认默认 500 题与图片可用。
2. 在自己的显示器、GUI 缩放和整合包字体下检查小窗口；搜索、切题、View、历史、
   导入、更新、关闭等按钮应始终可达，题目和控制台可滚动。
3. 粘贴多行 Java，运行正确答案、错误答案和语法错误。切题、关闭再打开、重启
   客户端后检查草稿；查看每题独立的控制台反馈。
4. 用自己实际使用的浏览器检查网页粘贴、切题与刷新。自动网页回归使用 Monaco
   paste action；游戏内回归通过 Ctrl+A / Ctrl+V 处理路径和隔离的剪贴板。
5. 在实际多人服务器确认积分、奖励、重复提交、离线/切题时提交结果与服务器
   通知一致。本轮服务器逻辑与序列化测试通过，未做两个真实客户端的完整网络拓扑。

网页的 Monaco / CSS 首次加载需要 CDN 网络。既有官方缓存不会被打包题库强制
替换；旧缓存需要更新时使用 Update Official。客户端证据来自 NeoForge 开发
运行环境，人工验收应加载构建出的 JAR 验证实际整合包。

测试必须后台静默、隐藏、无焦点、隔离输入和剪贴板。当前版本使用仓库内的独立测试入口，
工作区 `AGENTS.md` 同时记录了这条全局测试规则。
